# Budgeter

Personal finance and budget manager with double-entry accounting, smart budgets, balance sheet, net worth analytics, recurring bills, debt payoff & AI smart insights.

## Features
- **Double-entry bookkeeping & Transactions**: Multi-account ledger with comprehensive balance updates.
- **Dynamic Dashboard**: Financial overview, daily summaries, budget cards, and customizable widgets.
- **Budget Tracking & Maker**: Envelope budgeting and monthly budget management.
- **Balance Sheet & Payment Source Analysis**: Detailed asset/liability balances and payment source calculations.
- **Local Persistence & Sync**: Fast local SQLite persistence via Room with automated backup options.

## Built With
- Kotlin & Jetpack Compose
- Material Design 3
- Android Architecture Components (ViewModel, StateFlow, Room)
